# Bean to Bar Chocolate: one page site

Static site served from `docs/` (index.html, style.css, script.js, assets/).
No build step. Hosted with GitHub Pages: Settings > Pages > Deploy from a branch > main > /docs.

- Order links point to https://3achocolate.com/order
- Bar copy is in the `V` array in docs/script.js
- Colors are CSS variables at the top of docs/style.css
